CASE / 01
小红书内容获客与私域转化链路设计

从真实用户需求出发，用专业内容替代广告预算，建立「曝光 → 互动 → 私信 → 私域 → 成交」的自然增长闭环。

角色用户运营 / 增长策略
约束0 元广告预算
工具小红书 · Excel · AI

业务挑战

  • 预算有限，需要寻找可持续的自然获客方式。
  • 用户决策链路长，曝光并不等于咨询，更不等于成交。
  • 内容需要同时承担「被看见」与「建立信任」两项任务。

核心策略

  • 从用户真实提问中提炼高频需求，围绕搜索意图建立内容选题。
  • 用专业、可验证的信息建立内容信任，再设计评论区与私信承接。
  • 持续复盘曝光、互动、私信与成交数据，迭代选题与转化路径。
QUANTIFIED RESULT

≥4 单月度成交

复盘思考

这次项目让我确认：低预算增长的核心不是「发更多内容」，而是让内容与用户真实需求发生匹配，并把注意力进一步导向下一步行动。

PROJECT 02 USER RESEARCH · EYE TRACKING · DECISION

从“看见”到“行动”

CASE / 02
用户注意力与决策行为研究

研究用户如何看见信息、形成判断并做出行动，把心理学实验中的行为洞察翻译为内容与产品中的决策设计。

角色用户研究 / 实验设计
研究对象大学生篮球运动员
工具眼动实验 · 问卷 · 行为数据

业务挑战

  • 用户「看到了」并不意味着真正理解，更不代表会继续行动。
  • 需要识别注意力进入、信息加工与决策之间的关键摩擦。
  • 研究结论必须能够被转译成实际的内容与产品策略。

核心策略

  • 结合眼动实验与行为指标，观察用户的视觉注意与决策过程。
  • 从注意入口、认知负荷与信息层级提炼可解释的用户洞察。
  • 将研究结果转化为首屏优先级、信息层级、降低决策摩擦等策略。
